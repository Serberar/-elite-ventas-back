# Elite Ventas · Backend del CRM

Versión del backend del **CRM de Grupo Élite** para gestionar ventas, clientes, productos, grabaciones y firmas, con TypeScript, Express, Prisma y arquitectura hexagonal. El código está en [`code-back/`](code-back/), con su propia documentación detallada en [`code-back/README.md`](code-back/README.md).

La versión actual del backend está en [CRM-Elite-backend](https://github.com/Serberar/CRM-Elite-backend) y su frontend en [CRM-Elite-frontend](https://github.com/Serberar/CRM-Elite-frontend).

## Arranque rápido

```bash
cd code-back
cp .env.example .env
npm install
npm run dev
```
